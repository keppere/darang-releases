## 🛠️ Installation Guide

### Windows
1. Download the `Darang Setup X.Y.Z.exe` file.
2. Double-click to run the installer.
3. Follow the setup instructions. The app will launch automatically when finished.

### macOS
1. Download the `Darang-X.Y.Z.dmg` file.
2. Double-click to open the disk image.
3. Drag the **Darang** icon into your **Applications** folder.
4. Open the app from your Applications or Launchpad.

### Linux
*   **AppImage**: Download the `.AppImage` file, make it executable (`chmod +x Darang-X.Y.Z.AppImage`), and run it directly.
*   **Debian/Ubuntu**: Download the `.deb` package and install it using your package manager:
    ```bash
    sudo dpkg -i Darang-X.Y.Z.deb
    ```

## 🔄 Automatic Updates

Darang is built with a continuous release cycle. When a new version is released:
1. The application checks for updates in the background automatically on startup.
2. When a download completes, you will receive a subtle, non-intrusive floating notification.
3. Simply click **Restart Now** to apply the update in less than 5 seconds!
