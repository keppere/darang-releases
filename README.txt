## ✨ Features at a Glance

- **⚡ High-Performance Architecture**  
  Connect and run queries lightning-fast across multiple database dialects (MySQL, PostgreSQL, and more).

- **📓 Rich Database Notebooks**  
  Mix SQL queries, explanations, and dynamic visualizations in a unified document (`.dnb`) for robust data exploration.

- **🔒 Secure Password Storage**  
  Safe, native OS credential management via keytar.

- **💅 Premium User Experience**  
  - Sleek glassmorphic dark mode and customizable light/system themes.  
  - VSCode-like tabbed navigation and query history.  
  - Built-in SQL query formatter.  
  - Automatic background software updates.

## 🛠️ Installation Guide

### Windows
1. Download the `Darang Setup X.Y.Z.exe` file.  
2. Double-click to run the installer.  
3. Follow the setup instructions. The app will launch automatically when finished.  

### macOS
1. Download the `Darang-X.Y.Z.dmg` file.  
2. Double-click to open the disk image.  
3. Drag the **Darang** icon into your **Applications** folder.  
4. Open the app from Applications or Launchpad.
